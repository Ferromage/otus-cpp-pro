-----------------Протокол:
запрос от клиента на регистрацию:
<REGISTER> user_name,password
ответ сервера (успех):
<REGISTER> OK
ответ сервера (ошибка):
<REGISTER> FAIL error_description

запрос от клиента на вход:
<LOGIN> user_name,password
ответ сервера (успех):
<LOGIN> OK
ответ сервера (ошибка):
<LOGIN> FAIL error_description

запрос от клиента на отображение списка участников:
<LIST>
ответ сервера (успех):
<LIST> OK user1,user2, ... userN (разделитель - запятая без пробела)
ответ сервера (ошибка):
<LIST> FAIL error_description

запрос от клиента на отображение истории переписки с выбранным пользователем:
<HISTORY> user_name
ответ сервера (успех):
<HISTORY> OK <user>:<message>,<user>:<message>,<user>:<message>...<user>:<message>
ответ сервера (ошибка):
<HISTORY> FAIL error_description

отправка сообщения пользователю
<MESSAGE_TO> <user_name>:<message>
ответ сервера (успех):
<MESSAGE_TO> OK <user_name>:<message>
ответ сервера (ошибка):
<MESSAGE_TO> FAIL error_description

приём сообщений от других пользователей
<MESSAGE_FROM> <user_name>:<message>
